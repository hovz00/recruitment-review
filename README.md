# 招聘数据复盘

一个面向招聘复盘场景的浏览器端数据分析工具，通过招聘漏斗、阶段时效、流失原因和待推进候选人，帮助招聘人员快速定位招聘过程中的关键问题。

## 核心功能

- 招聘漏斗与关键转化指标
- 月度 / 周度趋势分析
- 阶段推进与招聘时效
- 流失原因分析
- 岗位、渠道、人选来源公司分析
- 候选人明细与需关注候选人
- 数据质量检查
- 招聘复盘与行动建议
- TXT 复盘报告导出
- 自定义招聘流程与阶段 SLA 配置

## 使用方式

1. 打开 `index.html`。
2. 根据实际招聘流程配置阶段。
3. 上传 `.xlsx` 或 `.csv` 招聘数据。
4. 完成必要的字段映射。
5. 查看数据复盘、复盘分析、分析明细及需关注候选人。

## 数据隐私

上传文件仅在当前浏览器中解析和分析。招聘数据不会由本项目上传至服务器。

## 数据口径

- “招聘记录”代表招聘申请或流程记录，不等同于去重候选人数。
- 总览漏斗采用累计到达口径。
- 阶段推进率采用已结案记录口径，当前库存不计入真正流失。
- 流失原因保留源数据中的原始原因。

## 技术实现

- HTML
- CSS
- Vanilla JavaScript
- 浏览器端 Excel / CSV 解析
- Playwright 自动化测试

## 测试

```bash
npm install
npm test
```

项目包含覆盖关键招聘口径、自定义流程、筛选状态、异常数据与核心回归场景的自动化测试。

## 本地运行

这是一个单文件应用，可直接打开 `index.html`，也可使用任意静态 Web Server 运行。
