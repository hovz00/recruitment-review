# 招聘数据复盘

一个面向招聘复盘场景的浏览器端分析工具。

通过招聘漏斗、阶段时效、流失原因和候选人跟进，帮助招聘人员从数据中快速 **看结果、找问题、查证据、跟行动**。

> 截图均使用虚拟数据，仅用于功能展示。

## 功能

系统包含 4 个页面：

- **总览**：查看招聘 KPI、漏斗、阶段时效、月/周趋势和流失原因。
- **复盘分析**：基于当前数据生成重点发现、数据依据和下一步建议。
- **分析明细**：进一步查看阶段、候选人、流失原因、岗位、渠道、人选来源公司和数据质量。
- **需关注候选人**：集中查看当前待推进、超 SLA、Offer 待入职等记录及建议动作。

### 月度 / 周度分析

支持按月或按周查看招聘趋势和流失原因变化。

## 数据口径

- **招聘记录**不等同于去重候选人数。
- 招聘漏斗采用**累计到达**口径。
- 阶段推进率基于**已结案记录**，当前库存不计入真正流失。
- 流失原因保留源数据中的原始记录。

## 使用

1. 配置招聘流程阶段与 SLA
2. 上传 `.xlsx` / `.csv`
3. 查看总览、复盘分析和分析明细
4. 跟进需关注候选人
5. 支持复制或下载复盘报告

## 隐私

招聘数据仅在当前浏览器中解析，不会上传至服务器。

## 技术

`HTML` · `CSS` · `Vanilla JavaScript` · `Playwright`

项目为单文件静态应用，可直接运行 `index.html`，也可部署至 Netlify 等静态托管平台。
